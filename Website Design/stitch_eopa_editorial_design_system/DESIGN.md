EOPA — Design System & Art Direction
Eastern Ontario Performance Artists Collective
This document defines the visual identity, design language, typography, colour system, layout principles, interaction design, animation, photography direction, responsive behaviour, and page-level art direction for the EOPA website.
The goal is to create a website that feels like a real contemporary Canadian arts organization — sophisticated, artistic, human, established, and intentionally designed.
The website should feel inspired by the editorial/institutional quality of Arts Ottawa, while developing a distinct EOPA identity.
Reference: https://www.artsottawa.ca/
Do NOT copy Arts Ottawa's layouts, branding, typography, colours, or exact compositions.
Use it as a reference for:
editorial confidence
cultural-institution visual language
strong typography
human photography
generous spacing
clear hierarchy
institutional credibility
contemporary Canadian arts presentation

01 — CORE CREATIVE DIRECTION
The feeling: EOPA should feel elegant, contemporary, artistic, human, intelligent, confident, warm, regional, cultural, editorial, sophisticated, slightly unconventional.
It should NOT feel corporate, generic, minimalist for the sake of minimalism, like a SaaS startup, like a festival landing page, like a generic nonprofit template, overly luxurious, overly playful, overly colourful, AI-generated, or empty.
Core concept: Contemporary arts institution × independent editorial publication × artist portfolio.
The website should feel as though a thoughtful art director designed it for an organization that actually works with artists.

02 — THE MOST IMPORTANT PRINCIPLE
Make it feel designed, not decorated.
Do not add visual elements simply because a section feels empty.
Do not add random shapes, blobs, gradients, excessive borders, decorative circles, giant background words, unnecessary badges, excessive pills, arbitrary oversized numbers, generic cards, or visual effects without purpose.
Instead, create visual interest through typography, photography, scale, cropping, composition, spacing, asymmetry, editorial rhythm, subtle motion, intentional contrast.
Every major visual element should have a reason to exist.

03 — VISUAL PHILOSOPHY
The site should NOT be extremely minimalist. It should have enough visual richness to feel like a contemporary cultural institution.
Elegant ≠ Empty.
The website should contain photography, editorial typography, thin rules, layered compositions, visual interruptions, varied section densities, subtle colour, movement, carefully chosen interactive details. But everything must remain restrained. The design should feel rich without feeling busy.

04 — COLOUR PALETTE
Restrained warm-neutral foundation with two controlled accent colours:
- INK: #262420 (Primary text, headings, body, navigation, icons, borders, major typographic elements. Warm editorial ink, avoid pure black)
- PAPER: #FBFAF7 (Primary page background, warm paper, editorial print, gallery walls)
- PLUM: #5D1274 (Primary EOPA accent, used sparingly for primary buttons, active navigation, important links, selected interactive states, occasional typographic emphasis)
- GROVE: #3A5D16 (Secondary accent, used quietly for footer, occasional rules, small labels, subtle section accents, regional references)

05 — LOGO ACCENT COLOURS
Logo accent colours (Magenta #940DBF, Violet #6B0EBF, Indigo #4717C1, Gold #EDD115, Amber #C27523) remain strictly within the logo identity and are NOT used as UI backgrounds, cards, buttons, or headlines.

06 — TYPOGRAPHY
- Primary display font: Fraunces (Weight 500) for H1, H2, important statements, editorial pull quotes, major section titles.
- Supporting font: Work Sans (Weight 400, 500, 600) for body copy, navigation, buttons, metadata, captions, event details, labels, forms.

07 — TYPOGRAPHIC SCALE
Responsive editorial scale:
H1: 40–64px
H2: 28–40px
H3: 20–25px
Body: 16–18px
Small: 13–14px
Metadata: 12–13px
Large editorial statement: 48–72px.

08 — LAYOUT & WHITESPACE
12-column desktop grid with generous horizontal margins. Content width max 1200–1400px. Asymmetric columns, offset elements, thin rules, varied section densities creating editorial rhythm. Contrast between dense informational sections and quiet reflective spaces.

09 — PHOTOGRAPHY & BUTTONS & INTERACTION
Documentary, intimate, human performance photography (medium 280–550px and small 120–220px, intentional crops, never full-bleed generic stock).
Editorial buttons with crisp 2-4px radii or understated borders.
Subtle, fast, cinematic motion (200–400ms transitions, gentle reveals, thin animated underlines).

10 — ANTI-AI-SLOP RULES
Never use generic card grids everywhere, floating blobs, gradients, excessive pills/badges, or repetitive templates. Each page carries distinct visual rhythm while sharing core EOPA DNA.
